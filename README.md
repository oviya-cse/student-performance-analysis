# Student Performance Analysis

## About the Project

This project analyzes student performance using Python and Pandas.

## Dataset

The dataset contains:
- Student Name
- Marks
- Attendance

## Technologies Used

- Python
- Pandas
- CSV

## Analysis Performed

- Calculate average marks
- Find highest marks
- Find lowest marks
- Calculate average attendance

## Project Structure

- `student_data.csv` - Student data
- `analysis.py` - Python analysis code
- `README.md` - Project documentation

## Future Improvements

- Add charts and visualizations
- Analyze attendance and marks relationship
